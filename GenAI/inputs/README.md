# Inputs

Git-ignored user media. Never commit private faces or videos.

- `comfyui/` — optional reference images
- `facefusion/source/` — authorized source faces
- `facefusion/target/` — target images/videos

See [docs/facefusion/10-consent-provenance-and-safety.md](../docs/facefusion/10-consent-provenance-and-safety.md).
